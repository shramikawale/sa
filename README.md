## MetaMask error

This project contains no MetaMask/Web3 integration. If Chrome reports `Failed to connect to MetaMask` from `chrome-extension://nkbihfbeoga.../inpage.js`, the message is being generated by the installed MetaMask extension. Disable MetaMask for localhost or test in a clean/incognito browser profile with extensions disabled.
